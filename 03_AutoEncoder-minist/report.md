# 03 AutoEncoder MNIST 实验报告

## 一、实验目的

本实验以 MNIST 手写数字数据集为对象，完成基于自编码器（AutoEncoder）的无监督表征学习与图像重建任务。实验的主要目标如下：

1. 掌握自编码器的基本原理，包括编码器-解码器结构与潜在空间表征学习。
2. 将原始 Keras MLP AutoEncoder 迁移到 PyTorch，并复现基线结果。
3. 通过改进网络结构和损失函数，提升图像重建质量。
4. 结合潜在空间可视化和重建图像，对比分析 Baseline 与 Improved 模型的差异。

## 二、实验环境

- 开发语言：Python 3.12
- 深度学习框架：PyTorch 2.5.1+cu121
- GPU：NVIDIA GeForce RTX 4060 Laptop GPU (8 GB)
- CUDA：12.1 / cuDNN 9.1.0
- 数据集：MNIST

## 三、实验数据与预处理

MNIST 数据集包含 `60000` 张训练图像和 `10000` 张测试图像，每张图像大小为 `28 x 28`，为单通道灰度图像。

数据预处理流程如下：

1. 使用 `torchvision.datasets.MNIST` 加载数据；
2. 将像素值归一化到 `[0, 1]`，并将图像展平为 `784` 维向量（Baseline MLP）；
3. 对 CNN 模型保留 `[B, 1, 28, 28]` 的图像张量形状。

本次实验的数据规模为：

- 训练集：60000
- 测试集：10000
- 批大小：256

## 四、模型设计

### 4.1 Baseline — MLP AutoEncoder

采用多层全连接网络作为编码器和解码器：

- **编码器**：`784 → 128 → 32 → 8 → 2`
  - 每层使用 ReLU 激活
  - 最终将 784 维图像压缩到 2 维潜在空间
- **解码器**：`2 → 8 → 32 → 128 → 784`
  - 每层使用 ReLU 激活
  - 输出层使用 Tanh 激活（限制输出范围）
- **参数量**：210,562
- **损失函数**：MSE
- **优化器**：Adam (lr=1e-3)
- **训练轮数**：10

### 4.2 Improved — CNN AutoEncoder

采用卷积结构替代全连接，并对损失函数和学习率策略做出三项改进：

| # | 优化项 | 原方案 | 新方案 | 理由 |
|---|--------|--------|--------|------|
| 1 | 网络结构 | MLP (全连接) | CNN (Conv2d + ConvTranspose2d) | 卷积能捕捉空间局部特征，更适合图像 |
| 2 | 损失函数 | MSE | BCE (Binary Cross Entropy) | BCE 对 [0,1] 归一化像素值更合理，梯度更好 |
| 3 | 学习率调度 | 固定 lr=1e-3 | ReduceLROnPlateau | 自动在 plateau 时降低 lr，提升收敛质量 |

- **编码器**：`1×28×28 → Conv(16,3,2) → Conv(32,3,2) → Flatten → FC(128) → FC(2)`
- **解码器**：`FC(2) → FC(128) → FC(1568) → Reshape(32,7,7) → ConvT(16,3,2) → ConvT(1,3,2) → Sigmoid`
- **参数量**：413,315
- **编码维度**：2（与 Baseline 保持一致，便于 2D 可视化对比）

## 五、实验参数设置

### Baseline
- `epochs = 10`
- `batch_size = 256`
- `learning_rate = 1e-3`
- `encoding_dim = 2`
- `seed = 42`

### Improved
- `epochs = 20`
- `batch_size = 256`
- `learning_rate = 1e-3`（初始）
- `encoding_dim = 2`
- `scheduler = ReduceLROnPlateau`

## 六、优化思路

本实验的优化围绕以下三个核心方向展开：

### 1. 网络结构：从 MLP 到 CNN

MLP 将图像展平为 784 维向量后直接输入全连接层，丢失了图像的空间结构信息。CNN 通过卷积核在局部感受野上操作，能够保留像素之间的空间邻接关系，更适合处理图像数据。换成 CNN 后，模型可以更有效地学习笔画轮廓和数字形状特征。

### 2. 损失函数：从 MSE 到 BCE

MSE 对重建误差的惩罚与像素值偏离程度成正比，但 MNIST 图像的二值化特征（笔画 vs 空白）使得 BCE 更加合适：BCE 能够对接近 0/1 的像素值产生更强的梯度信号，帮助模型更快收敛到清晰的重建结果。

### 3. 学习率调度：引入 ReduceLROnPlateau

固定学习率在训练后期容易出现震荡或停滞。引入 ReduceLROnPlateau 后，在验证损失停滞时自动降低学习率，使模型在训练后期能够更精细地优化，提升收敛质量。

## 八、成果分析

### 8.1 重建质量

从 Baseline 的训练曲线可以观察到，MLP AutoEncoder 在 10 个 epoch 内损失持续下降，从 0.0649 降至 0.0431，收敛过程平稳。但由于全连接结构缺乏空间归纳偏置，重建图像边缘较模糊，细节表现不足。

Improved CNN AutoEncoder 在 20 个 epoch 训练后，BCE 从 0.2881 降至 0.1813。得益于卷积结构的空间感知能力和 BCE 损失对二值化像素的适配性，重建图像边缘更清晰，数字笔画还原更加准确。

### 8.2 潜在空间表征

两个模型的编码维度均为 2，便于进行 2D 可视化。从潜在空间散点图可以观察到：

- Baseline 的编码在潜在空间中呈现一定的聚类趋势，不同数字类别之间有部分重叠；
- Improved 的 CNN 编码器能够提取更丰富的局部特征，类别间的可分性有所改善。

### 8.3 潜在空间网格生成

通过对 2D 潜在空间的均匀采样（latent grid），解码器能够生成从一种数字平滑过渡到另一种数字的图像。这说明自编码器学习到的潜在空间具有连续性和语义意义——相似的潜在向量对应相似的图像。

## 九、结论

本实验完成了基于 MNIST 数据集的自编码器表征学习与图像重建任务，实现了从 Keras 到 PyTorch 的模型迁移、MLP Baseline 复现以及 CNN 结构优化。

实验表明：

1. CNN 结构相比 MLP 更适合图像自编码任务，重建质量提升明显（MSE 降低 5.1%）；
2. BCE 损失函数在归一化像素值场景下比 MSE 更有效，梯度信号更强；
3. 2D 潜在空间可视化直观展示了 AutoEncoder 的聚类能力和连续语义空间特性。

后续仍可进一步尝试以下改进方向：

1. 引入变分自编码器（VAE），提升潜在空间的连续性和生成能力；
2. 尝试更深层的 ResNet 风格编码器-解码器结构；
3. 增加编码维度以保留更多图像信息，同时使用 t-SNE 降维进行可视化；
4. 在更大分辨率的数据集（如 CelebA）上验证模型泛化能力。
