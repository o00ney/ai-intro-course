# 02_GAN_MNIST 实验报告

## 一、实验目的

本实验以 MNIST 手写数字数据集为对象，完成基于生成对抗网络（GAN）的图像生成任务。实验的主要目标如下：

1. 掌握 GAN 在无监督图像生成任务中的基本思想与训练流程。
2. 理解生成器与判别器之间的对抗关系，以及训练平衡对生成效果的影响。
3. 完成 MNIST 灰度图像的读取、归一化、模型搭建、训练与可视化输出。
4. 结合训练曲线与生成样本，对模型收敛情况和生成质量进行分析。

## 二、实验环境

- 开发语言：Python 3.11
- 深度学习框架：TensorFlow / Keras
- 加速方式：`tensorflow-metal`
- 数据集：MNIST
- 任务类型：无监督图像生成

## 三、实验数据与预处理

MNIST 数据集包含 `60000` 张训练图像和 `10000` 张测试图像，每张图像大小为 `28 x 28`，为单通道灰度图像。本次实验主要使用训练集进行生成模型训练。

数据预处理流程如下：

1. 使用 `tensorflow.keras.datasets.mnist` 直接读取 MNIST 数据集。
2. 将原始二维图像扩展为 `28 x 28 x 1` 的张量形式。
3. 将像素值从 `[0, 255]` 线性归一化到 `[-1, 1]`。
4. 采用固定批大小构造训练批次，并在每个 epoch 前进行随机打乱。

本次实验中模型实际使用的数据规模为：

- 训练集：`60000`
- 批大小：`128`
- 每个 epoch 的 step 数：约 `468`

## 四、模型设计

本实验采用卷积式 GAN 结构，主要由生成器和判别器两部分组成。

模型主要结构如下：

- 生成器（Generator）
  - 输入：`100` 维随机噪声
  - `Dense(7 x 7 x 256)` + `BatchNormalization` + `LeakyReLU`
  - `Reshape(7, 7, 256)`
  - `Conv2DTranspose(128)` + `BatchNormalization` + `LeakyReLU`
  - `Conv2DTranspose(64)` + `BatchNormalization` + `LeakyReLU`
  - `Conv2DTranspose(1, activation='tanh')`
  - 输出：`28 x 28 x 1` 生成图像

- 判别器（Discriminator）
  - 输入：`28 x 28 x 1` 图像
  - `Conv2D(64)` + `LeakyReLU` + `Dropout`
  - `Conv2D(128)` + `LeakyReLU` + `Dropout`
  - `Flatten`
  - `Dense(1)` + `sigmoid`
  - 输出：图像为真实样本的概率分数

损失函数采用二元交叉熵，优化器采用 `Adam(beta_1=0.5)`。  
其中，生成器负责将随机噪声映射为数字图像，判别器负责区分输入图像是真实样本还是生成样本。

## 五、实验参数设置

根据本次保存在 `gan_results/training_summary.json` 的训练记录，实验使用的主要参数如下：

- `epochs = 50`
- `batch_size = 128`
- `sample_interval = 2`
- `d_learning_rate = 2e-4`
- `g_learning_rate = 2e-4`
- `beta_1 = 0.5`
- `real_label = 0.9`
- `seed = 42`

训练过程中，每隔 `2` 个 epoch 保存一次固定噪声下的生成图像，用于比较模型在不同训练阶段的输出质量变化。

## 六、实验过程与优化思路

本次实验过程中，模型训练主要围绕生成质量与训练稳定性展开，重点考虑以下几个方面：

### 1. 使用卷积式生成器和判别器

卷积结构更适合处理图像局部空间特征，能够更有效地学习笔画轮廓与数字形状，从而提高生成样本的可辨识度。

### 2. 保留适度的对抗平衡设置

实验中将生成器与判别器的学习率统一设为 `2e-4`，并使用 `beta_1 = 0.5` 的 Adam 优化器，以保持较平稳的更新过程。  
同时，将真实标签平滑为 `0.9`，减轻判别器过快饱和的问题。

### 3. 以图像质量为主要评价依据

对于生成模型而言，`loss` 和 `score` 并不总是与视觉效果严格一致。  
因此，本次实验除了记录 `d_loss`、`g_loss`、`real_score` 和 `fake_score` 外，更关注固定噪声下生成图像从噪声到数字轮廓的变化过程。

## 八、成果分析与结论

从本次实验结果可以看出，当前卷积式 GAN 已经能够在 MNIST 数据集上生成具有明显数字结构的图像。  
在训练初期，模型输出主要表现为随机噪声；随着训练进行，到 `epoch_010` 左右时，生成样本已经出现较明显的数字轮廓；在 `epoch_050` 时，大部分样本已经能够被识别为手写数字，说明生成器成功学习到了 MNIST 数据分布中的基本笔画与形状特征。

从指标上看，判别器损失整体稳定在 `1.37` 左右，生成器损失稳定在 `0.80` 左右，`real_score` 始终略高于 `fake_score`。  
这说明模型训练过程总体较为平稳，没有出现明显发散现象，但判别器对真实样本和生成样本的区分能力仍然有限，两者分数差距较小，表明当前对抗过程已经趋于稳定但尚未达到较强判别能力。

结合生成图像和训练曲线可以认为，本实验已经实现了基于 GAN 的 MNIST 数字生成目标，模型能够输出可辨识的手写数字图像。  
不过，最终结果仍存在边缘模糊、笔画断裂、少量样本失真以及数字多样性不足等问题，说明当前模型虽然完成了基本生成任务，但距离较高质量的图像生成效果仍有提升空间。

后续仍可进一步尝试以下改进方向：

1. 增强生成器与判别器的卷积层深度和通道数，以提升图像细节质量；
2. 引入更稳定的对抗训练方式，如 `WGAN-GP`；
3. 使用学习率调度或保存中间最佳模型，以减轻后期训练退化问题；
4. 在报告中加入更多不同 epoch 的样本对比图，以更直观展示生成质量的变化过程。
