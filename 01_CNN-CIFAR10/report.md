# 01 CNN CIFAR-10 实验报告

## 一、实验目的

本实验以 CIFAR-10 数据集为对象，完成卷积神经网络图像分类任务，并围绕模型训练过程中的优化方法展开分析。实验的主要目标如下：

1. 掌握 CIFAR-10 原始批文件的读取与预处理方法。
2. 理解卷积神经网络在图像分类任务中的基本结构与训练流程。
3. 通过调整学习率、正则化、数据增强与早停机制，提高模型训练稳定性和泛化能力。
4. 结合实验结果分析模型在训练集、验证集和测试集上的表现差异。

## 二、实验环境

- 开发语言：Python 3.11
- 深度学习框架：TensorFlow / Keras
- 加速方式：`tensorflow-metal`
- 数据集：CIFAR-10

## 三、实验数据与预处理

CIFAR-10 数据集共包含 10 个类别，每张图像大小为 `32 x 32`，为三通道彩色图像。实验中使用官方提供的 Python 批文件格式数据：

- `data_batch_1 ~ data_batch_5`：训练数据
- `test_batch`：测试数据
- `batches.meta`：类别名称信息

数据预处理流程如下：

1. 将原始 `3072` 维向量恢复为 `32 x 32 x 3` 图像。
2. 将像素值归一化到 `[0, 1]`。
3. 从训练集中按类别分层划分验证集，比例为 `0.1`。
4. 根据训练集统计得到的均值和标准差，对训练集、验证集和测试集进行标准化。

本次实验的数据规模为：

- 训练集：45000
- 验证集：5000
- 测试集：10000

## 四、模型设计

本实验采用 `keras.Sequential` 搭建卷积神经网络，整体结构由数据增强模块、三层卷积特征提取模块和两层分类模块组成。

模型主要结构如下：

- 输入层：`32 x 32 x 3`
- 数据增强层：随机翻转、随机平移、随机旋转、随机缩放
- 卷积层 1：`Conv2D(32, kernel_size=5)` + `MaxPool2D` + `BatchNormalization` + `Dropout`
- 卷积层 2：`Conv2D(64, kernel_size=3)` + `MaxPool2D` + `BatchNormalization` + `Dropout`
- 卷积层 3：`Conv2D(64, kernel_size=3)` + `MaxPool2D` + `BatchNormalization` + `Dropout`
- 全连接层：`Dense(128)` + `Dropout`
- 输出层：`Dense(10, activation='softmax')`

损失函数采用 `SparseCategoricalCrossentropy`，优化器采用 `Adam`。

## 五、实验参数设置

根据最新一次训练记录，本次实验使用的主要参数如下：

- `epochs = 120`
- `batch_size = 64`
- `learning_rate = 5e-4`
- `min_learning_rate = 1e-5`
- `clipnorm = 1.0`
- `L2_WEIGHT = 1e-4`
- `dense_dropout = 0.3`
- `RandomZoom = 0.1`
- `cutout_probability = 0.0`
- `EarlyStopping patience = 15`
- `EarlyStopping min_delta = 1e-4`

从训练记录看，模型实际训练了 `103` 个 epoch，并在验证集表现不再继续提升后提前停止训练。

## 六、优化思路

实验过程中，模型训练主要围绕以下几个方面进行优化：

### 1. 控制训练发散

早期实验中曾出现训练后期损失急剧增大、准确率下降的现象。针对这一问题，后续引入了以下策略：

- 使用较小的初始学习率；
- 通过 `clipnorm` 控制梯度更新幅度；
- 使用 `ReduceLROnPlateau` 在验证损失停滞时自动降低学习率；
- 使用 `EarlyStopping` 避免无效训练。

这些方法有效提高了训练的稳定性，使模型能够保持较平滑的收敛过程。

### 2. 抑制过拟合

为了提升泛化能力，实验在卷积层和全连接层中加入了 `L2` 正则和 `Dropout`。  
同时，在输入端保留随机翻转、平移、旋转和缩放等基础增强操作，以增强模型对样本变化的适应能力。

### 3. 平衡正则化强度

实验结果表明，正则化和增强策略并非越强越好。若 `Dropout`、`L2` 或增强幅度设置过大，容易导致模型学习不足。  
因此，本次实验采用相对适中的参数组合，在稳定训练和保持识别精度之间取得平衡。

## 七、实验结果

根据本次训练自动生成的 `final_metrics.json`，模型最终结果如下：

| 数据集 | Loss | Accuracy |
| --- | ---: | ---: |
| Train | 0.7249 | 77.63% |
| Validation | 0.7619 | 76.40% |
| Test | 0.7810 | 75.95% |

补充说明：

- 最佳验证集准确率：`76.46%`
- 最佳验证结果对应 epoch：`91`
- 实际训练轮数：`103`

从每轮记录来看，模型在前 10 个 epoch 内准确率提升较快，随后逐步进入稳定收敛阶段。后期验证集指标波动较小，说明模型训练已经接近收敛状态。

## 八、成果分析

从本次实验结果可以看出，模型在训练集、验证集和测试集上的表现较为接近，说明当前模型具有较好的泛化能力。  
其中，训练集准确率为 `77.63%`，验证集准确率为 `76.40%`，测试集准确率为 `75.95%`。训练集与验证集之间的差距较小，未出现明显的严重过拟合现象。

同时，测试集准确率与验证集准确率较为接近，说明验证集划分具有一定代表性，模型在未参与训练的数据上仍保持了较稳定的识别性能。  
结合训练日志可以看出，学习率调度和早停机制在本次实验中发挥了较好的作用，使模型在保持训练稳定的同时取得了较好的分类结果。

总体而言，本次实验结果优于前期训练不稳定或正则化过强的版本，说明当前这组参数设置更适合本次 CIFAR-10 分类任务。

## 九、结论

本实验完成了基于 CIFAR-10 数据集的卷积神经网络分类任务，实现了数据读取、图像预处理、模型搭建、训练优化和结果评估的完整流程。  
实验表明，学习率、正则化强度、数据增强方式以及早停策略都会对模型性能产生显著影响。

通过本次实验可以得到以下结论：

1. 合理的学习率控制和梯度约束能够有效避免训练发散。
2. 适度的 `Dropout` 与 `L2` 正则有助于提升模型泛化能力。
3. 早停机制能够减少无效训练，并保留验证集表现最好的模型。
4. 在当前配置下，模型已经能够在 CIFAR-10 数据集上取得较稳定且较合理的分类效果。

后续仍可进一步尝试以下改进方向：

1. 优化卷积层通道数和卷积核配置；
2. 采用更精细的学习率调度策略；
3. 尝试更系统的数据增强对比实验；
4. 在报告中加入类别级别的混淆矩阵与错误样本分析，以进一步提升实验分析深度。
